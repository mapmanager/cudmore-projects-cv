I am applying for the Research Software Engineer – Image Analysis & Microscopy position. My career combines a foundation in computer science, a PhD in Neuroscience, more than 20 years of experimental biology research, and extensive experience designing and developing scientific software. My microscopy experience includes laser-scanning imaging of living tissue, dissociated and organotypic cultures, and anesthetized and awake animals. I have designed experiments, built custom acquisition systems, analyzed data, and published biological findings. This background gives me practical judgment about image formation, sampling, calibration, noise, and the difference between a computational result and a valid scientific measurement. I use that expertise to translate research questions into algorithms, data models, and interfaces while working closely with both experimental scientists and software engineers.

AcqStore and CloudScope are representative of how I build image-analysis platforms. AcqStore is a general-purpose Python backend with public APIs for loading, managing, and analyzing imaging data. Its implemented methods include Radon-based blood-flow velocity, threshold and gradient-based diameter measurements, spectral heart-rate estimation, and event detection followed by feature extraction. Parallel execution accelerates independent calculations, while lazy data access supports collections containing hundreds of raw-data files and datasets too large to load in full. CloudScope uses this backend to connect interactive analysis with curation, allowing researchers to inspect detections against raw images, identify false positives and false negatives, and preserve review decisions alongside completed results.

I design data formats and software boundaries so these methods remain useful beyond one application. AcqStore and CloudScope save raw images, metadata, analysis parameters, and results in schema-defined Zarr collections using OME-Zarr conventions for images. The same computational methods are available to graphical applications, scripts, and notebooks, while a static browser application presents completed analyses as interactive published figures. Automated tests, continuous integration, API documentation, full user documentation, and reproducible distribution are part of the implementation rather than later additions.

My broader image-software portfolio demonstrates the same emphasis on reusable methods. MapManager supports alignment, annotation, curation, and measurement across longitudinal microscopy sessions, with a shared Python backend serving desktop, browser, scripting, and notebook workflows. Brightest Path implements scale-aware A* and bidirectional A* tracing in n-dimensional images, uses Numba for acceleration, and provides both a documented Python package and an interactive napari interface. These projects reflect my ability to develop scientific algorithms and then package them as dependable components that other researchers and engineers can extend.

I remain a hands-on developer while guiding architecture, coordinating work, and mentoring engineers. NIH and Chan Zuckerberg Initiative funding has enabled me to build multidisciplinary teams in which software developers and research biologists work toward shared scientific and technical goals. I have also taught scientific methods and computing through lectures and laboratory courses and mentored trainees in computer science, biophysical engineering, and biomedical engineering.

I would welcome the opportunity to contribute this combination of microscopy expertise, algorithm design, research software architecture, and collaborative technical leadership to Johns Hopkins DSAI. I am excited by the prospect of working with faculty, scientists, and other RSEs to build open, maintainable software that advances imaging research across projects and disciplines.
