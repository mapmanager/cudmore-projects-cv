This experience helps me understand the constraints imposed by each imaging modality and incorporate them into analysis software so computational results remain connected to scientifically valid measurements. I also enjoy collaborating with specialists outside my direct expertise, combining their domain knowledge with my experience to develop reusable, reproducible analysis software that can serve more than one project.

AcqStore and CloudScope show how I build image-analysis platforms. AcqStore is a general-purpose Python backend with public APIs for loading, organizing, and analyzing microscopy data. Plugins extend its file-loading, analysis, and export capabilities, while parallel execution and lazy data access support batch analysis across large collections and datasets too large to load in full. CloudScope is a desktop and web GUI that uses the same backend for interactive analysis and human-in-the-loop curation, allowing researchers to inspect results against raw images and preserve review decisions with completed results. Together, these systems provide direct evidence of my experience with the position’s data-science pathway: transforming raw data into structured measurements and building processing pipelines and data models for complex scientific datasets at scale.

My general approach is to separate computation, storage, and presentation so analytical methods can be reused and extended without duplicating their implementation. The same computations serve graphical applications, scripts, notebooks, and published browser views. Schema-defined Zarr collections preserve raw images, metadata, analysis parameters, and results, while OME-Zarr conventions support interoperability. Automated testing, continuous integration, developer and user documentation, and reproducible distribution support long-term maintenance and help turn solutions developed for individual projects into reusable scientific infrastructure.

My broader image-software portfolio demonstrates the same emphasis on reusable methods. MapManager supports large-scale longitudinal tracking of individually identified neuronal structures, with rapid expert review across collections containing tens of thousands of annotations. This human-in-the-loop workflow helps prevent annotation errors from obscuring small biological changes. Brightest Path implements A* tracing in n-dimensional images, uses Numba for acceleration, and provides both a documented Python package and an interactive napari interface.

I remain a hands-on developer while guiding architecture, coordinating work, and mentoring engineers. NIH and Chan Zuckerberg Initiative funding has enabled me to build multidisciplinary teams of software developers and research biologists working toward shared scientific and technical goals. I also teach scientific computing and mentor trainees across computer science and engineering.
