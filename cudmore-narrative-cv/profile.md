Robert H. Cudmore, PhD

Research Software Engineer & Scientist

I build scientific software that transforms complex biological data into reproducible quantitative measurements.

My work combines biology, software engineering, and computational analysis to develop reusable scientific software for microscopy, electrophysiology, behavioral research, and scientific imaging. I work closely with experimental scientists to design software that supports the complete scientific workflow—from data acquisition and real-time analysis to quantitative measurement, publication, and long-term reuse.

Research Software Engineering

I develop reusable scientific software that combines documented Python APIs, graphical applications, scripting interfaces, and modern software engineering practices into sustainable research platforms. My work emphasizes transparent analytical methods, reproducible computational workflows, and software that can evolve alongside new scientific questions rather than being rewritten for individual projects.

A central principle of my work is that the same computational backend should support every interface. Researchers should be able to perform identical analyses through desktop applications, Python scripts, browser-based tools, or future interfaces without changing the underlying implementation. This approach improves reproducibility, interoperability, and long-term maintainability while allowing software to serve researchers with a wide range of computational backgrounds.

I am particularly interested in scientific software that supports the complete lifecycle of research. The same software should assist researchers while experiments are being performed, provide reproducible analysis after data collection, and ultimately accompany published datasets so future investigators can inspect data, repeat analyses, perform new measurements, and build computational models using the same analytical methods.

Scientific Expertise

My research has spanned neuroscience, cardiovascular physiology, cell and molecular biology, electrophysiology, laser-scanning microscopy, computational modeling, and behavioral experiments. Working across these disciplines has shown me that many biological questions rely on the same experimental methodologies and quantitative analytical approaches. This perspective has led me to develop software that generalizes across scientific domains rather than being tied to a single experimental technique.

Scientific Software Platforms

My software platforms address different scientific problems while sharing a common engineering philosophy centered on reusable computational infrastructure.

CloudScope

An open-source platform for microscopy image analysis supporting reproducible measurements, interactive visualization, scalable data analysis, desktop and web deployment, and software that accompanies published datasets.

SanPy

An open-source platform for transparent electrophysiology analysis that combines graphical applications with documented Python APIs for reproducible and extensible quantitative analysis.

MapManager

An open-source platform for visualization and longitudinal analysis of neuronal morphology that emphasizes interactive exploration, reusable data models, and collaborative scientific workflows.

PiE

An open-source platform for behavioral acquisition that integrates instrumentation, experiment monitoring, image acquisition, and quantitative analysis into reproducible experimental workflows.

Software Engineering

My software development practices include reusable Python libraries, documented APIs, automated testing with pytest, continuous integration using GitHub Actions, end-user documentation with MkDocs, and automated desktop application builds for macOS and Windows. I develop desktop scientific applications using PyQt and NiceGUI and build serverless scientific applications using WebAssembly and Pyodide. My recent work also emphasizes scalable scientific data using HDF5, Zarr, OME-Zarr, NGFF, and lazy-loading architectures capable of supporting datasets much larger than system memory.
